Guide

C# scripting

Behaviour in Vertex is written as components: small C# classes added to objects. The same components work in a game made only in code and in one made in the editor. This page is a tour of what you'll use most. Every type and member is in the C# API.

A component

using System.Numerics;

using Vertex;

public class Spinner : Component
{
    [Range(0f, 720f)]
    [Tooltip("Degrees a second")]
    public float Speed { get; set; } = 90f;

    protected override void Update()
    {
        Transform.EulerAngles += new Vector3(0f, Speed * Time.DeltaTime, 0f);
    }
}

In the editor, Add Component › New Script writes one of these for you. In code, gameObject.AddComponent<Spinner>() adds it. Either way, a component's GameObject is the object it's on, and Transform is that object's position, rotation and scale.

When things are called

Override any of these; leave out the ones you don't need.

MethodCalled
Start()Once, just before the component's first Update. Find things and set up here.
Update()Every frame. Read input, move things that aren't physics, update UI.
FixedUpdate()Before every physics step, a fixed number of times a second (60 unless the project says otherwise). Push rigidbodies here.
OnCollisionEnter(Collision), …Stay, …ExitWhen the object's collider starts, keeps, or stops touching another.
OnTriggerEnter(Collider), OnTriggerExitWhen something goes into or out of a trigger collider (one with IsTrigger on).
OnNetworkEvent(NetworkEvent)When a network event about this object (or about no object) arrives. See Multiplayer.
OnDestroy()When the component or its object is destroyed.

Settings in the inspector

Public properties with a getter and a setter (and public fields) are shown in the inspector and saved with the scene or prefab. Attributes change how:

public class Turret : Component
{
    [Header("Aiming")]                          // a titled section
    [Range(1f, 50f)] public float Range { get; set; } = 20f;    // a slider
    [Tooltip("Degrees a second")] public float TurnSpeed { get; set; } = 120f;

    [Header("Firing")]
    public Prefab? Bullet { get; set; }         // a slot for a prefab file
    public AudioClip? FireSound { get; set; }   // ...a sound
    public GameObject? Barrel { get; set; }     // ...another object in the scene
    public Light? Lamp { get; set; }            // ...an object's Light component
    public List<GameObject> Targets { get; set; } = new();     // saved, but not edited in the inspector yet

    [HideInInspector] public int ShotsFired { get; set; }     // saved, not shown
    [DontSave] public float Heat { get; set; }                  // shown, not saved
}

Shown and saved: numbers, true/false, text, vectors, colours, enums (as a dropdown), ranges (FloatRange, a smallest and largest), materials (edited in place), and slots for textures, materials, prefabs, sounds, fonts, visual scripts, VFX graphs, other objects and their components. A slot for another object is filled by dragging the object from the outliner, or by clicking it and picking from a list.

Objects, finding and making

// Other components on the same object, or below it.
var body = GetComponent<Rigidbody>();
var model = GameObject.GetComponentInChildren<MeshRenderer>();

// Things elsewhere in the scene.
GameObject? door = GameObject.Find("Door");
NetworkManager? network = Scene.Active.FindComponent<NetworkManager>();
foreach (Light light in Scene.Active.FindComponents<Light>()) light.Intensity *= 0.5f;

// Making things.
var lamp = new GameObject("Lamp");
lamp.Transform.Position = new Vector3(0f, 3f, 0f);
lamp.AddComponent<Light>(light => { light.Type = LightType.Point; light.Range = 8f; });
GameObject crate = GameObject.CreateCube(new Vector3(2f, 0.5f, 0f), Color.Orange);

// Copies of a prefab.
Prefab rocket = Prefab.Load(Application.AssetPath("Prefabs", "Rocket.prefab"));
GameObject fired = rocket.Instantiate(Transform.WorldPosition, Transform.WorldRotation);

// Gone at the end of the frame (with everything under it).
crate.Destroy();

Children: set child.Transform.Parent = parent.Transform. Position, Rotation and EulerAngles are relative to the parent; WorldPosition and WorldRotation aren't. Forward, Right and Up are the ways an object faces, in the world (forward is −Z).

Time

Time.DeltaTime is how long the last frame took, in seconds: multiply speeds by it so things move the same at any frame rate. Time.TotalTime is the seconds since the game started; Time.FixedDeltaTime is the length of a physics step.

Input

if (InputSystem.GetKey(Key.W)) { }              // held
if (InputSystem.GetKeyDown(Key.Space)) { }      // pressed this frame
if (InputSystem.GetKeyUp(Key.E)) { }            // let go this frame
if (InputSystem.GetMouseButtonDown(MouseButton.Left)) { }
Vector2 look = InputSystem.MouseDelta;          // how far the mouse moved this frame
Vector2 at = InputSystem.MousePosition;          // where it is in the window
float wheel = InputSystem.ScrollDelta;
InputSystem.CursorLocked = true;                 // hide the pointer and keep it in the window, to look round

Physics

A collider gives an object a shape (Box, Sphere, Capsule, Mesh, Convex). Alone it doesn't move: walls, floors. Add a Rigidbody and physics moves it: it falls, bounces, and can be pushed.

var body = GetComponent<Rigidbody>()!;
body.AddForce(Vector3.UnitY * 20f);       // over time (call in FixedUpdate)
body.AddImpulse(Vector3.UnitY * 5f);      // all at once: a jump, a knockback
body.Velocity = Vector3.Zero;

// What's in front of the camera?
Transform eye = Camera.Main!.Transform;
if (GameObject.Scene.Physics.Raycast(eye.WorldPosition, eye.Forward, 100f, out RaycastHit hit))
{
    Log.Info($"Looking at {hit.GameObject.Name}, {hit.Distance:0.0} m away");
}

For players, a CharacterController is easier than a rigidbody: set its Velocity and call Move(Time.DeltaTime) each frame, and it slides along walls, climbs steps and stands on slopes. IsGrounded says whether it's on something. Its position is at its feet. The Duel's PlayerMovement is a full example.

For a third-person camera, put a Spring Arm on the camera and make the camera a child of the character. It holds the camera behind and above the character, turns it round with the mouse, and pulls it in when a wall's in the way, so the character is never hidden. It can lag a little as it follows, look over a shoulder (Offset), and sway like a camera held in the hand. Move the character the way the camera faces with FlatForward and FlatRight:

var arm = Camera.Main!.GetComponent<SpringArm>()!;
Vector3 move = arm.FlatForward * forward + arm.FlatRight * sideways;   // from WASD
controller.Velocity = move * Speed;

The arm finds walls with Scene.Physics.SphereCast, which game code can use too: a raycast with thickness, for what a ball would hit on its way.

Scenes and files

Scene.Load("Scenes/Level 2.scene");          // switch level (the old one's objects go)
Scene.Active.Add("Scenes/Bonus Room.scene");  // add a scene's objects to this one

// Files in the game's Assets folder.
Texture grass = Assets.LoadTexture(Application.AssetPath("Textures", "Grass.png"));
Material brick = Assets.LoadMaterial(Application.AssetPath("Materials", "Brick.material"));
AudioClip boom = Assets.LoadSound(Application.AssetPath("Sounds", "Boom.wav"));

Each file is loaded once and shared, so asking again is cheap. Load files with Application.AssetPath so they're found however the game's run, in the editor or not.

Sound

Sound.Play(boom);                                 // the same everywhere: UI, music
Sound.PlayAt(boom, Transform.WorldPosition, 0.8f); // from a place: quieter further away

Both give back a PlayingSound, to ask whether it's still playing (IsPlaying) or Stop() it.

UI

Two kinds. Drawn each frame from code, quick for a score or a debug readout:

Canvas.DrawText(Font.Default, $"Score {score}", new Vector2(20f, 20f), Color.White, 28f);
if (Gui.Button(Font.Default, "Play again", new Vector2(20f, 70f), new Vector2(180f, 44f))) Restart();

And made of objects, laid out in the editor's Game tab: a UICanvas with UIText, UIImage, UIPanel and UIButton under it, each placed by its UIRect. Set uiText.Text from a script to change what it says.

Messages

Log.Info("Level loaded");
Log.Warning("No spawn points: starting at the middle");
Log.Error("Couldn't read the save file", exception);

They show in the editor's Console, and in the game's own console (the ` key).

A game class

Components are enough for most games. A Game class is for code that runs for the whole game: in a code-only game it builds the world, and in an editor game it can run around your scenes. See Code and the editor.

Talking to visual scripts

VisualScript script = GetComponent<VisualScript>()!;
script.SetVariable("Speed", 8f);
object? health = script.GetVariable("Health");
VisualScript.SendEvent("Alarm", GameObject);   // starts On Event "Alarm" in every visual script

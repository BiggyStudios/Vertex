Download

Get Vertex

The editor, the engine and the samples, in one download for Windows, Linux or macOS. Unpack it and go.

Vertex is in pre-alpha. It's for trying out and experimenting: expect bugs, missing features, and changes that break projects from one version to the next. It isn't recommended for production games yet.

macOS won't open programs from the internet that aren't signed with an Apple developer account. Once, before the first run, open a terminal in the unpacked folder and run xattr -dr com.apple.quarantine . (the dot too). The download is for Macs with Apple silicon; on an Intel Mac, build from source.

Run the editor from a terminal. It needs your distribution's Vulkan or OpenGL drivers (Mesa, or your GPU maker's).

Get going

1

Install .NET 10

Get the .NET 10 SDK. The editor runs on it, and builds C# scripts and games written in code with it.

2

Unzip

Unpack the download anywhere: your documents, a games folder. Nothing is installed.

3

Open the editor

Run Editor\Vertex.Editor.exe. Then File › Open Project, pick Samples\Duel\Duel.vertexproject, and press Play.

Getting started takes it from there: flying round the editor, the samples, and making your own project.

The engine's package

For games written in code, the engine comes as a NuGet package, in the download's Engine folder. Projects inside the download's folder find it by themselves (that's what its nuget.config is for), so the quickest start is to copy Starter and run it:

cd Starter
dotnet run

For a project anywhere else, tell .NET where the package is once, then add it as you would any other:

dotnet nuget add source "C:\Games\Vertex-0.1.0\Engine" --name Vertex
dotnet add package Vertex.Engine --version 0.1.0

Use the path you unpacked to. The Coin Grab tutorial makes a whole game this way.

Every release

Newest first. Each has what changed, and its downloads.

Build from source

For the newest changes before they're in a release, or to change the engine itself. You need the .NET 10 SDK and Git:

git clone https://github.com/BiggyStudios/Vertex.git
cd Vertex
dotnet build Vertex.slnx
dotnet run --project Vertex.Editor

The repository has the same Samples folder, so everything in the docs works the same from source. Games made in code refer to the engine's project instead of its package: <ProjectReference Include="..\Vertex\Vertex\Vertex.csproj" />.

Making a release (for the engine's maintainers): push a version's tag, git tag v0.2.0 then git push origin v0.2.0. GitHub tests it, builds the downloads, and publishes them here. See .github/workflows/release.yml.

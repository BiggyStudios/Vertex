Particles and VFX graphs

Two ways to make sparks, smoke, flashes and magic: a Particle System with settings to tweak, or a VFX graph designed with nodes. Both play in the scene view while they're selected, so you see changes as you make them.

Particle System

Add a Particle System component to an object. Its settings come in sections:

SectionWhat's in it
EmissionHow many a second (Rate), a Burst all at once, how long it lasts and whether it Loops, the most alive at once, and whether the object goes when it's finished (for one-off effects).
ShapeWhere they start: a box, a sphere or a circle, from inside or the edge, and whether they head outwards from it.
ParticlesHow long they live, how big, what colour from start to end, how they look (Soft, Disc, Square, Ring, Spark), rotation and spin, glow, stretching along their movement, fading in.
MovementDirection, spread, speed, gravity, drag, turbulence, and whether they move with the object (Local Space) or are left behind.

Selected, it plays in the scene view with a bar to restart or pause it and a count of particles alive. Ranges like Lifetime and Speed take a smallest and largest, and each particle gets a value between them.

From code or a visual script: Play() starts it from the beginning (the Play Effect node), Stop() stops making new ones, and Emit(count) lets out a burst now (Emit Particles). A muzzle flash, for example, is a burst with Emitting and Loop off, played on each shot.

VFX graphs

For effects that need more than settings: particles whose size follows a curve over their life, colours from a gradient, swirling noise, values the game can change. Make one with Effects & Audio › VFX Graph on the Assets panel's + menu (or press the button on a Visual Effect component), and play it with a Visual Effect component. A VFX graph has four steps, wired in order, and values feeding into them:

StepDecides
SpawnHow many are made: a rate, a burst, how long, whether it loops.
InitializeEach particle as it's made: where (link a shape: Point in Sphere, Point on Circle, Direction in Cone…), how fast and which way, how long it lives, its size and colour.
UpdateEvery frame of its life: forces (gravity, wind, a Swirl of noise), drag.
OutputHow it's drawn: size and tint (link Curve or Gradient by the particle's Life to change them as it ages), its look, glow, blending.

Value nodes read the particle (Age, Life from 0 to 1, a random number of its own, position, velocity), the effect (its time, where it is), and properties: values the graph declares, set per object from the game. In C#:

var fire = GetComponent<VisualEffect>()!;
fire.SetProperty("Strength", 2.5f);     // a number property
fire.SetProperty("Tint", Color.Orange);  // a colour property
fire.Restart();

A system can make several kinds of particle at once: each Spawn → Initialize → Update → Output chain is one. All the VFX nodes are in the node reference, under VFX Graph.

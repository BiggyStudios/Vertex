A game engine in C#

A 3D game engine, with its own editor.

Lay out scenes and prefabs in the editor, give objects behaviour with C# or visual scripts, and press Play to try it. Physics, sound, effects and multiplayer are built in.

Making things happen

What an object does comes from the scripts on it. Write them in C#, or wire them up from nodes.

C# scripts

A component is a C# class with Start, Update, collisions and network events. Its properties show in the inspector, and objects and prefabs can be dragged into them.

public class Spinner : Component
{
    public float Speed { get; set; } = 90f;

    protected override void Update()
    {
        float turn = Speed * Time.DeltaTime;
        Transform.Rotate(new Vector3(0f, turn, 0f));
    }
}

What it uses

Vertex is built on libraries proven in other engines and games, with graph editors of its own for effects and sound.

◆
Vulkan and OpenGL

Physically based lighting, shadows, sky and clouds, fog and bloom. Vulkan where the graphics card has it, OpenGL 3.3 where it doesn't.

⬢
Jolt Physics

Rigidbodies, colliders, triggers, raycasts, and a character controller that climbs steps and slides along walls.

♪
OpenAL Soft

Sound in 3D: it comes from objects, follows them as they move, and gets quieter further away.

⇆
Steamworks

Multiplayer through Steam lobbies, or over the local network. Networked objects, synced movement and network events.

VFX graphs

Design particle effects with nodes: where particles start, how they move, and their colour and size over their life. They play in the editor as you change them.

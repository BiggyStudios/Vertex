A game engine in C#

Make games your way: in code, or in the editor.

Vertex is a 3D engine with its own editor. Write the whole game in C#, build it in the editor with C# scripts, or wire it up with visual scripting. It's the same engine underneath, so you can mix all three.

Three ways to make a game

Pick the one that suits you, or the job in front of you. None of them locks you in.

Code only

A whole game in C#, no editor needed. Build the world in a few lines and run it with new MyGame().Run().

  • Great for programmers and prototypes
  • Everything in source control as code
  • Open it in the editor any time

They work together

A code-only game opens in the editor. A game made in the editor can still do things in code. Use whichever is quicker for each part.

Code

From code, use what's made in the editor

Open a level with Scene.Load("Scenes/Arena.scene"), make copies of prefabs, and find objects by name. Your C# components work in the editor too.

Editor

In the editor, add code where it helps

Write a component in C#, or give the game a Game class that runs around your scenes. C# can read and set a visual script's variables, and both get the same network events.

What's in it

Everything a small multiplayer 3D game needs, with an editor that's quick to learn.

◆
Vulkan and OpenGL

Physically based lighting, shadows, sky and clouds, fog, bloom and soft shadowing. Vulkan first, OpenGL when it isn't there.

⬢
Jolt physics

Rigidbodies, colliders, triggers, raycasts, and a character controller that climbs steps and slides along walls.

⇆
Multiplayer

Steam lobbies (Spacewar's app ID for testing) or the local network. Networked objects, synced movement and network events.

✺
Particles and VFX graphs

Particle systems with bursts, shapes and turbulence, or design effects with nodes. They play in the editor as you change them.

▤
Prefabs

Reusable objects that open in a tab of their own. Changes reach every copy, and undo puts them back.

♪
Sound and UI

3D sound, and audio graphs: a random one of several sounds at a random pitch, layered, looped. A UI of canvases, text, images and buttons.

↶
Undo for everything

Every edit in the editor can be undone, a drag of a number included, and Play puts the scene back when you stop.

⌕
Docs from the engine

The node reference and C# API here are made from the engine itself, so they match the version you have.
